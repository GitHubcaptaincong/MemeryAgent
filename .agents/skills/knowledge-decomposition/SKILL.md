# Knowledge Decomposition

## 目标

把用户材料拆成 1–10 个知识单元。每个单元应回答一个清晰的问题，并能独立用于后续复习。

## 规则

1. 优先按概念、因果关系、步骤或适用边界拆分，不按固定字数机械切割。
2. 一个单元只承担一个主要学习目标。
3. 材料不足以支持的结论必须标为不确定，不得补写成事实。
4. 生成开放问题，避免仅要求识别或背诵原句。
5. 每个单元保留来源字符区间和短引文。
