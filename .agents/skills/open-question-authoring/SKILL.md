# Open Question Authoring

## 目标

用开放问题检查用户能否解释、应用或比较知识，而不只是复述原句。

## 规则

1. 问题应能在不展示原文的情况下独立理解。
2. 答案键使用要点列表，允许合理的不同措辞。
3. 提示由弱到强，不直接泄露完整答案。
4. 若问题有多个合理答案，明确评分边界。
5. 不把模型置信度当作用户掌握度。
