# 阶段五：长文本与公开链接来源

状态：已完成本地实现与验证，尚未验证云端部署（2026-08-17）

## 本阶段目标

把“粘贴短文本后整理”扩展为两种可追溯输入：

1. 粘贴最长 50,000 字的文本或 Markdown。
2. 提交一个无需登录即可访问的公开 HTTP/HTTPS 网页，由系统提取正文后进入现有 Agent 整理与草稿确认流程。

完整学习闭环保持不变：

`材料输入 → Source 持久化 → Agent 拆解 → 原文证据校验 → 用户确认 → 进入复习`

## 已确认的产品边界

- 图片、截图、OCR、视觉模型本阶段不做。
- 公开链接授权只表示“允许读取用户明确提交的这个链接”。
- “允许外部检索”仍是独立开关；本阶段没有接入真实搜索工具，也不会沿网页链接自动扩展搜索。
- 不支持登录页、Cookie、验证码、付费墙、文件下载和需要浏览器执行 JavaScript 才能显示的正文。
- 不把抓取成功等同于内容正确；用户仍需确认知识草稿。
- 聊天式 Agent 首页保留为阶段 5B。本阶段先复用现有整理工作台验证来源链路。

## 用户体验

整理页使用一个统一材料输入框：

- 输入内容是单个 HTTP/HTTPS 链接时，由服务端识别并读取该链接。
- 混合说明文字与 URL 时按普通文本保存，不擅自打开其中链接。
- 输入框显示实时字数和 50,000 字上限。
- 提交链接时显示“正在解析链接”；成功后显示解析出的正文字符数。
- 解析失败时给出可行动错误，例如地址不是公网、页面类型不支持、正文为空、页面过长或读取超时。
- Agent 任务轨迹使用限高滚动列表；任务结束后自动折叠，并允许点击摘要重新展开或收起。

## 安全与证据

公开链接抓取必须：

- 只允许 HTTP/HTTPS，拒绝 URL 中的账号和密码。
- DNS 解析结果全部必须是公网地址；拒绝 localhost、内网、链路本地、回环、保留地址。
- 每次重定向重新执行 URL 和公网地址校验。
- 固定连接到已校验 IP，同时保留原域名用于 Host 与 TLS 校验。
- 限制超时、响应体大小和重定向次数。
- 只接收 HTML、XHTML 和纯文本。

网页 Source 保存最终 URL、抓取时间、原始响应哈希和解析后正文。生成的每条 Source 证据继续使用精确字符范围和原文摘录，并补充 URL 与抓取时间。

## 验收范围

- 10,001–50,000 字文本可以保存并进入 Agent 流程。
- 50,001 字以上请求被明确拒绝，不静默截断。
- 无需登录的公开 HTML 页面可提取正文并创建 Source。
- 内网地址和跳转到内网的地址在发出对应请求前被拒绝。
- 非 HTML/纯文本、空正文、超长正文和抓取失败返回可理解错误。
- URL Source 的草稿证据包含最终 URL 与抓取时间。
- H5 与微信小程序均提供统一文本/链接输入入口。
