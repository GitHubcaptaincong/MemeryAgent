# 小程序前四项优化交付记录

实施日期：2026-10-20。

对应 `ui-interview-review-2026-10-20.md` 的“微信小程序：优先优化项”1—4；本次没有修改 H5 演示或发布云端。保留工作区原有修改。

## 1. 整理过程回看

- 每个有任务的对话轮次常驻“整理过程”入口，不再依赖 `busy`；无草稿的失败任务也可进入。
- 新增整理过程页，按任务 ID 重新读取持久化任务状态和全部可见事件（`after_seq=0`），支持历史对话和手动刷新。
- 默认展示读取材料、生成知识点、校验证据、等待确认四步；状态根据实际事件和任务状态计算，没有记录的步骤明确标注。
- 可展开具体事件，查看时间、工具名称、证据定位成功/未定位数量、结构校验问题数；任务错误同页展示。

主要文件：`miniprogram/pages/process/`、`miniprogram/utils/run-history.js`、`miniprogram/pages/capture/`。

## 2. 确认操作外置、逐条审阅

- 结果卡顶部常驻“待确认 / 已加入复习”状态与主要操作，不需滚过全部详情才能确认。
- 展开知识点列表后，各知识点可独立展开/收起，保留其他知识点的展开状态。
- 确认通过卡片自身的草稿 ID 提交，历史待确认草稿也可操作；确认期间防止重复提交和切换对话。
- 确认后提供“立即复习”和“查看知识集”。立即复习按该知识集筛选到期题目。

## 3. 原文证据定位

- 整理结果、复习答案、知识集详情均提供“查看依据”，使用同一个原文页。
- 原文页支持多条依据切换、引用区间高亮、自动滚动到引用处和完整原文阅读；来源链接可复制。
- 使用后端保存的规范化原文快照，而不是重新抓取网页。按 Unicode 码点处理区间，避免 emoji 导致位置偏移。
- 区间缺失、越界或引文不匹配时明确提示，不猜测位置；读取失败可以重试，快速切换依据时丢弃旧响应。
- 引文提高到正文可读字号。

新增接口契约（FastAPI 自动纳入 OpenAPI）：

```text
GET /api/v1/sources/{source_id}
认证：沿用 get_current_identity
200：SourceDetailRead = 原 SourceRead 字段 + raw_content: string
401：缺少必要身份
404：不存在、不属于当前用户或已删除
422：source_id 不是合法 UUID
```

不涉及数据库结构迁移。小程序与后端需一起更新；旧后端没有这个 GET 接口。

## 4. 复习步骤与切题保护

- 显示“作答 → 对照 → 自评”，提交后四档自评按钮固定在底部导航上方，并保留每档下次复习时间预览。
- AI 详细缺失点默认折叠；AI 等待、失败或关闭时仍可自评，最终排期继续使用用户评分。
- 当前小程序页面会话内按卡保存草稿、提交结果、展开状态和重试幂等键；切题、查看原文返回、切换队列和刷新时恢复。
- 提交/评分期间锁定切题及队列切换；回答响应检查卡片与请求标识，AI 轮询检查卡片、答题记录及轮询代次，丢弃过期响应。
- 评分成功移除当前卡、恢复下一题草稿并更新进度；响应不明确时只允许原评分和原幂等键重试。
- 静默同步期间继续输入的内容也会保存，避免刷新覆盖新草稿。

草稿暂存在页面内存中，未实现关闭小程序后的持久化恢复。

## 仍需开发者工具/真机验收

1. 长材料和多条证据：切换依据，确认高亮、定位滚动和全文阅读；检查含 emoji 的材料。
2. 长答案和多项 AI 建议：评分区始终可见，内容不被遮挡；键盘、窄屏和安全区布局正常。
3. 弱网提交时尝试切题，返回后草稿/结果保持；AI 超时后仍能评分并正确进入下一题。
4. 待确认、已完成、失败任务及历史会话均能回看真实事件。
5. 后端与小程序更新后，完成真实材料 → 确认 → 原文 → 复习 → 自评闭环。
